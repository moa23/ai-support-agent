# AI Support Agent

An AI-powered IT support assistant built with FastAPI and OpenAI. The application analyzes user-submitted IT issues, classifies them into support categories, and generates practical troubleshooting guidance.

## Features

- **AI-powered troubleshooting:** Generates contextual responses to IT support requests.
- **Automatic categorization:** Classifies issues into email, network, performance, account, or general support.
- **Input validation:** Validates incoming messages using Pydantic.
- **Error handling:** Handles failures from the OpenAI API without exposing internal error details to API clients.
- **REST API:** Provides a simple HTTP interface using FastAPI.
- **Automated tests:** Tests API behavior and error scenarios without making real OpenAI API calls.

## Tech Stack

- Python
- FastAPI
- OpenAI API
- Pydantic
- Pytest

## Getting Started

### Prerequisites

- Python 3.11 or newer
- An OpenAI API key with available API credits

### 1. Clone the repository

```bash
git clone https://github.com/moa23/ai-support-agent.git
cd ai-support-agent
```

### 2. Create and activate a virtual environment

On macOS or Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Configure the API key

Create a `.env` file in the project root:

```env
OPENAI_API_KEY=your_api_key_here
```

Replace the placeholder with your own OpenAI API key.

**Security:** Never commit your `.env` file or expose your API key publicly.

### 5. Start the application

```bash
uvicorn main:app --reload
```

The API will be available at:

`http://127.0.0.1:8000`

Interactive API documentation is available at:

`http://127.0.0.1:8000/docs`

## Example Request

Send a `POST` request to `/support` with the following JSON body:

```json
{
  "message": "I can receive emails, but my colleagues never receive the messages I send."
}
```

Example response:

```json
{
  "message": "I can receive emails, but my colleagues never receive the messages I send.",
  "response": "Check your outgoing mail settings and investigate whether the messages are being rejected or placed in a queue.",
  "category": "email"
}
```

The response text is generated by the AI and may differ between requests.

## Support Categories

| Category      | Example issue                         |
| ------------- | ------------------------------------- |
| `email`       | Problems sending or receiving email   |
| `network`     | Wi-Fi or internet connectivity issues |
| `performance` | A slow computer or application        |
| `account`     | Login or account access problems      |
| `general`     | Other IT support requests             |

## Running Tests

Run the automated test suite:

```bash
python -m pytest -v
```

The tests mock the OpenAI API, allowing the suite to run without consuming API credits.
